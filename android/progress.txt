   in those packages. These libraries already ship consumer ProGuard rules. Reduced to only
   app-specific rules (JNI, TTS service, dictionary JSON data classes). FIXED.

- String resources: All keys present in default, hr, and sr locale files
- AndroidManifest: Correct service declarations, intent filters, activity registrations
- ProGuard rules: Comprehensive keep rules for JNI, Hilt, Compose, DataStore
